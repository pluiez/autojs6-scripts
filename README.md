# autojs6-scripts

在 Android 手机上用 [AutoJs6](https://github.com/SuperMonster003/AutoJs6) 运行的自动化脚本合集。

## 运行环境

- [AutoJs6](https://github.com/SuperMonster003/AutoJs6/releases)（开发时使用 v6.7.0）
- 测试设备：OnePlus 13T（ColorOS），无 root
- 需要授予 AutoJs6 的权限：
  - **无障碍服务**：查找和点击界面控件，所有脚本都需要
  - **[Shizuku](https://shizuku.rikka.app/)**（可选）：执行 shell 命令，比如清理最近任务。脚本会在 Shizuku 不可用时退回到兜底方案
  - **通知**：用来发送执行结果
  - **后台弹出界面**：ColorOS、MIUI/HyperOS、OriginOS 等系统需要开启，否则后台弹出的 toast 可能显示不出来

## 使用方法

1. 把需要的脚本复制到手机上，用 AutoJs6 打开。
2. 先手动运行一次，在 AutoJs6 的日志里确认每一步都正常。
3. 在 AutoJs6 里给脚本设置定时任务，让它每天自动运行。为了让定时任务准时触发：
   - 授予 AutoJs6"**闹钟和提醒**"权限。AutoJs6 默认用 AlarmManager 精确闹钟触发定时任务，没有这个权限，熄屏或待机时可能被系统推迟。
   - 在 ColorOS 等系统中，允许 AutoJs6 **自启动**、**后台运行**，电池优化设为"**不限制**"。否则到点时 AutoJs6 可能已经被系统清掉了。

脚本顶部的"配置"区放着可以调整的参数，比如超时时间、包名、界面文字等。

## 工作流

### `auto_steps/`：刷步与鹅厂运动领取 Q 米

| 脚本 | 说明 |
|---|---|
| `auto_steps.js` | 在 AutoTasks 中手动刷随机步数，再打开微信小程序"鹅厂运动"领取 Q 米，最后清理最近任务，通过通知和 toast 播报结果。被启动就直接执行 |
| `remind.js` | 定时任务指向它。响铃并发一条"点击执行"通知，点击后运行 `auto_steps.js` |

两个脚本必须放在同一目录下。

执行流程：

1. **AutoTasks 刷步**：用包名打开 AutoTasks（`ts.auto.tasks`），点任务卡片上的"手动"，在弹窗输入框里填入 7000–10000 之间的随机步数，点"开始刷步"。弹窗关闭后 AutoTasks 会弹出一条很短的"刷步成功" toast，脚本在点击前就开始监听，以此判断是否成功。（AutoTasks 的定时刷步是付费功能，所以用"手动"按钮。）
2. 移除 AutoTasks 的最近任务卡片，并强制停止它（通过 Shizuku）。
3. 打开微信，先判断它当前停在哪个界面，再拉出小程序面板，找到"鹅厂运动"并打开。常用列表里没有时，改用搜索。
4. **等待步数同步**：小程序打开后要过 1–2 秒才会同步步数。脚本读取"今日步数"卡片里的"当前步数 / 达标线"，步数仍为 0 时点一次"刷新"再等。
5. **按按钮文字判断状态**：
   - "马上瓜分今日Q米"：点击领取，从弹窗"今日已成功瓜分Q米"中读出领取的数量，再点"坐等收米"关闭弹窗；
   - "今日奖励已领取"：今天已经领过；
   - "还差 N 步……"：步数没达标。
6. 只移除鹅厂运动的最近任务卡片，微信保持运行。
7. 发一条通知，同时弹一条 toast 播报结果，例如"✅ 领取 1.05 Q米"、"ℹ️ 今日奖励已领取"、"❌ 步数未达标（3200/6666）"。

定时运行：在 AutoJs6 中给 **`remind.js`**（不是 `auto_steps.js`）设置每天 22:00 的定时任务。到点后：

1. `remind.js` 响铃并弹出一条"到点了，点击此通知开始执行今日打卡"的通知。无论手机当时是否解锁，都是这样。
2. 你拿起手机，锁着的话先自己解锁，然后下拉通知栏点这条通知，`auto_steps.js` 开始执行。

其他情况：

- 在 AutoJs6 里手动运行 `auto_steps.js` 时，会直接执行。之前留下的提醒通知会被自动清除。
- `auto_steps.js` 启动时如果发现手机锁着屏，会调用 `remind.js` 重新发一条提醒通知，然后退出。
- 提醒通知用的是单独的"打卡提醒"通知渠道，重要性为"高"。想调整铃声或振动，到系统设置里 AutoJs6 的通知设置中修改这个渠道。

注意事项：

- 配置区的 `MP_MIN_CENTER_Y` 是在测试设备上测出来的像素值，换手机后需要重新测量。
- 微信相关的界面文字配置同时列出了中文和英文写法，以适配系统语言切换。
- 各环节的等待时间（`*_TIMEOUT`）都在配置区，网络慢时可以调大。
- `DEBUG_DUMP` 为 `true` 时，脚本会在 AutoTasks 弹窗、鹅厂运动首页、领取弹窗这几个界面，把所有带文字的控件打印到日志，用于确认控件结构。确认无误后可以关掉。
